# UI / UX Change Skill

Use when the task affects layout, components, styles, forms, responsiveness, accessibility, or visual behavior.

## Focus
- Identify affected page/component, shared usage, design system/theme, and desktop/mobile behavior.
- Keep labels, forms, focus states, and responsive layout usable.

## Guardrails
- Do not redesign unrelated areas.
- Prefer existing components, tokens, spacing, and style patterns.
- Do not add heavy dependencies, random colors, or unnecessary animations.
- Preserve accessibility basics.
